peng cheng 要求写 skill、入库规则和说明时，只写做什么的核心原则，不写防御性、不做什么的措辞；规则越少越好；越具体的设置越优先。

**Why:**
2026-11-10 在 edges PR #120 的 skill 重构讨论中，peng cheng 强调不要一堆 if else，逻辑越简单越稳。防御性和「不做什么」的措辞会把一条原则拆成很多分支。

**How to apply:**
写 skill、入库规则和说明时，只写做什么的核心原则；规则越少越好；同一件事有多条设置时，越具体的那条优先。
