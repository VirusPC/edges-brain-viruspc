AI News 的项目开源卡和精选文章卡共用 `site/src/components/NoteCard.astro`。改这个组件或它的样式时，按下面六条做。用户 2026-11-21 定稿，同日验收后又改了三条：小标题贴左、关键词在生成时写入源稿、暗色荧光笔单独配色。

1. 整页只用一套视觉语言。卡片里的分类和来源用筛选栏同款胶囊，分类用该分类的颜色，来源白底灰框。卡片里的字全用宋体，不另引一套字体。
2. 在原有卡片上做最小改动，不堆纸张装饰。不要横线纸、页边线、胶带、倾斜，也不要改卡片底色、边框和标题原来的位置、颜色、下划线。横线如果和字对不齐，会干扰阅读。
3. 层次靠字号、字重和颜色小步拉开。标题、完整总结、正文、小标题各挪一小步，不做夸张的大小落差。
4. 强调只留荧光笔一种，而且用得省。一句话总结的关键词在写周报时就用一处 `<mark>` 包进源稿并入库，短语必须是原句里已有的，不改写原句。站点构建只渲染这个标记，不在页面里挑词。没有标记就不划。「洞察与启发」整句用同一支荧光笔。其他段不做特殊处理。暗色不要用半透明黄压在深底上，那会发绿发脏；暗色单独用亮黄底、深色字，保证对比度。
5. 结构让人一眼扫完。桌面端小标题贴左，灰棕色、不加粗、不换行，和正文首行对齐。标签列按该卡最长的小标题（通常是「洞察与启发」）收紧，和正文之间留适中的间距，左侧不要留出一大块空白。窄屏大约 520px 及以下，小标题回到正文上方。
6. 能删的装饰就删。小标题下的弧线、相关段单独改成灰色、小标题右对齐留下的空档，这类可有可无的处理都不加。留下的每个元素都有用处。

展示名只改第一段：源稿仍写「解决什么问题」，卡片上显示「什么问题」。如何解决、效果怎样、洞察与启发、相关工作保持原名。折叠标题仍叫「完整总结」。

**Why:**
验收时右对齐的小标题把字推到列的右侧，左侧空得太大，扫读时对不齐。关键词如果等页面打开再猜，每期都会漂。半透明黄在深色卡片上和底色混成橄榄绿，字看不清。

**How to apply:**
- 项目开源和精选文章都走 `NoteCard.astro`。没有分类、来源、一句话或某一段时照样能排。
- 筛选栏的样式文件不要改。卡片上的胶囊复用同一套 class。
- 小标题在桌面端 `text-align: left`，列宽用 `max-content`，不要再改回右对齐。
- 新周报在 `skills/managed/weekly-ai-blogs-digest` 写总结时就把 `<mark>` 写进一句话。不要在站点里补关键词。
- 暗色荧光笔改色时看文字对比，不要只调低黄色透明度。
- 小标题显示名仍在展示层映射。源稿继续写「解决什么问题：」。
