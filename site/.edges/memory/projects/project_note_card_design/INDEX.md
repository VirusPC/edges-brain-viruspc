AI News 的项目开源卡和精选文章卡共用 `site/src/components/NoteCard.astro`。改这个组件或它的样式时，按下面这些做。用户 2026-11-21 定稿，同日验收后改过：小标题贴左、关键词写入源稿、暗色荧光笔用下半截暖琥珀、卡片垂直节奏按 4px 网格。同日又定了筛选栏：一整块钉住的手绘木牌，不要底部红棕粗线。2026-11-21 晚至 2026-11-22 凌晨（Asia/Shanghai）又确认：卡片标签与筛选栏同一套字体和边框，筛选栏三行标题背景透明，来源类型与来源公司联动，各卡片外轮廓用手绘轻微描边。

1. 整页只用一套视觉语言。卡片里的分类和来源用筛选栏同款胶囊，分类用该分类的颜色，来源白底灰框。卡片里的字全用宋体。暗色下分类胶囊的文字和描边要提亮，和底色的对比至少 4.5:1，亮色胶囊不动。
2. 在原有卡片上做最小改动，不堆纸张装饰。不要横线纸、页边线、胶带、倾斜，也不要改卡片底色、边框和标题原来的颜色、下划线。外轮廓的手绘描边见第 12 条，那是后来单独定的，不要在它之外再改边框。
3. 层次靠字号、字重和颜色小步拉开。标题、完整总结、正文、小标题各挪一小步。
4. 强调只留荧光笔一种，而且用得省。一句话总结的关键词在写周报时就用一处 `<mark>` 包进源稿并入库，短语必须是原句里已有的。站点只渲染这个标记。「洞察与启发」整句用同一支荧光笔。亮色和暗色都是 linear-gradient 只涂文字下半截（约 55%–90%）。暗色用偏暖的琥珀色、大约 0.32 不透明度，文字保持浅色正文色，不要改成深色字，也不要铺成整块实心黄。
5. 桌面端小标题贴左，灰棕色、不加粗、不换行，和正文第一行基线对齐。标签列按「洞察与启发」收齐。窄屏大约 520px 及以下，小标题回到正文上方，和自己的正文只留约 4px，和上一段拉开。
6. 垂直节奏用 `.note-card` 上的 CSS 变量，跟 4px 网格：组内紧、组间松。正文行高约 1.68；段与段 16px；标题行到一句话 8px；一句话到「完整总结」10px；「完整总结」到第一段 12px；卡片上下内边距相等（16px）；卡片间距 20px，略大于段间距。
7. 能删的装饰就删。小标题下的弧线、相关段单独改灰、右对齐留下的空档，都不加。
8. 筛选栏是一块钉住的手绘小木牌，包住三行。不要在筛选栏底部另加一条红棕粗线，木牌自己有边。亮色：竖向渐变 `#ecd9b8` → `#e6cfa8`，很淡的横向木纹，圆角约 10px，2px 边 `#8a5a34`。边缘抖动用 `#wood-rough`：`feTurbulence` fractalNoise、`baseFrequency` 0.02、`numOctaves` 2，`feDisplacementMap` scale 3.5。下方厚度 `0 3px 0 #b88a5e`，再加 `0 8px 18px rgba(80,50,20,.18)`。顶部两角各一颗 12px 金属钉。只旋转木牌背景层约 -0.5deg，文字不转，避免发糊，也不要把 `transform` 加在 sticky 元素上。行与行之间是拼缝：一条轻微起伏的深棕细线 `rgba(105,65,30,.38)` 约 1.3px，紧贴其下一条亮色高光 `rgba(255,246,228,.75)` 1px，两端淡出。用 SVG path，`vector-effect: non-scaling-stroke`，宽度跟着筛选栏走。行标题亮色 `#6e3220`，字号和字重保持原样。三行标题的背景透明，不要纯色底（2026-11-22 00:01，Asia/Shanghai）。
9. 筛选栏里，全部、来源类型、来源公司这些中性胶囊未选中用暖白 `#fffaf0`、描边 `#bba98f`，好在木底上浮起来。分类胶囊仍用各分类自己的颜色。选中态是深棕粗边 `#3a2a1c`（约 2.5px）。未选中字重是 400。选中（含「全部」）才升到 600，不要升到 700 或更重。中性胶囊选中文字亮色 `#2a1d12`。彩色分类选中时文字用各自色系更深一档：模型 `#1a3d7a`，架构 `#3d3268`，产品 `#8c3e12`，实践 `#1b4f34`，开源 `#0a4f4f`，其他 `#4a3424`。2026-11-22 00:41（Asia/Shanghai）用户改口：文章卡和项目卡上的分类、来源类型、公司标签也可以点击过滤和反向过滤，选中态、非选中态的字体和边框与筛选栏一致。00:49 又确认文章卡片里的文章类型标签也可以点选筛选。卡片标签的选中态和非选中态都走筛选栏那一套，不再停在未强调胶囊上。
10. 暗色做成胡桃木，不要刺眼。底 `#4a3526` → `#3a281c`，边 `#c4a27a`，木纹更淡，厚度阴影改深。拼缝是暗缝 `rgba(0,0,0,.45)` 加淡暖高光 `rgba(255,230,200,.35)`。行标题 `#f0d2b8`，背景同样透明，不要纯色底。中性胶囊底 `#53402f`、描边 `#c6aa8c`，选中边 `#f3e4d4`、选中字 `#fff8f1`，字重同样是未选中 400、选中 600。分类选中文字再提亮一档：模型 `#e8f1ff`，架构 `#f6f1ff`，产品 `#ffe6d8`，实践 `#e7fff2`，开源 `#e9ffff`，其他 `#fff1e6`。标题和胶囊对比至少 4.5:1。窄屏三行在木牌内部横向滑动，钉子和边留在牌上，不跟着裁掉。吸顶仍是筛选栏容器，背景层的旋转不破坏 sticky。卡片标签在暗色里也跟随筛选栏的选中态和非选中态，字体和边框一致。
11. 来源类型和来源公司要联动（2026-11-22 01:33，Asia/Shanghai）：选来源类型时，来源公司自动回到「全部」；选来源公司时，来源类型不跟着变。来源类型只列出该类型下的公司。
12. 各卡片外轮廓用手绘（Rough.js）轻微描边。词云、模型榜单、模型介绍、文章卡的圆角保持一致，转角要接上。2026-11-21 23:08–23:34（Asia/Shanghai）一带提出，随后已在站点落地。

展示名只改第一段：源稿仍写「解决什么问题」，卡片上显示「什么问题」。折叠标题仍叫「完整总结」。

**Why:**
实心亮黄在暗色里把整段洞察画成警告条。半透明黄如果太淡又会和深底混脏，所以暗色仍用下半截笔触，但换成更暗的琥珀，字保持浅色。分类胶囊沿用亮色的深色字，在深底上对比不够。段与段如果只靠行高分开，展开后像一整块。筛选栏如果只在底部加一条红棕粗线，框不住三行；2026-11-21 用户在对比稿里改选一整块木牌，标题和选中字跟牌同一套深棕。同日验收后又定了：未选中胶囊保持 400，只有选中升到 600。2026-11-22 00:41（Asia/Shanghai）用户改口：卡片标签也可以点击过滤和反向过滤，因此卡片里的标签选中态、非选中态样式应与筛选栏一致，包括字体和边框。00:49 文章卡片里的文章类型标签也可以点选筛选。00:01 筛选栏三行标题的背景应透明，不要纯色底。01:33 来源类型和来源公司要联动：选来源类型时，来源公司自动回到「全部」；选来源公司时，来源类型不跟着变。来源类型只列出该类型下的公司。2026-11-21 23:08–23:34 一带提出各卡片外轮廓用手绘（Rough.js）轻微描边，词云、模型榜单、模型介绍、文章卡的圆角保持一致，转角要接上，随后已在站点落地。

**How to apply:**
- 项目开源和精选文章都走 `NoteCard.astro`。间距只改 `--note-gap-*`、`--note-pad-y`、`--note-leading`。
- 新周报在 `skills/managed/weekly-ai-blogs-digest/references/03-并行写总结.md` 写总结时就把 `<mark>` 写进一句话。不要在站点里补关键词。
- 暗色荧光笔不要改回实心黄或深色字。暗色分类色只加在暗色主题上。
- 小标题显示名仍在展示层映射。源稿继续写「解决什么问题：」。
- 木牌颜色只改 `.ai-news-filter` 上的 `--wood-*`。显式暗色和系统暗色都要设。
- 手绘抖动只加在木牌背景层。文字不要放进同一个滤镜。
- 筛选栏和卡片标签都是未选中字重 400、选中 600。卡片上的分类、来源类型、来源公司、文章类型标签与筛选栏对应胶囊使用同一套字体和边框；`aria-pressed` 为真时一起变，再点一次反向取消。
- 筛选栏三行标题背景透明，不要加纯色底。亮色、暗色、桌面和窄屏都一样。
- 选来源类型时，来源公司回到「全部」，并只列出该类型下的公司。选来源公司时，来源类型保持不动。
- 词云、模型榜单、模型介绍、文章卡的外轮廓用 Rough.js 轻微描边，圆角保持一致，转角要接上。
