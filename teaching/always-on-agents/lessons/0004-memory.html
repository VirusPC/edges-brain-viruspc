Memory

只存查不回来的东西：用独立的耐用存储，接住多次互不相连的 run 之间的连续性。

第 4 课 · 约 10 分钟 · 主来源：William Hu · Building always-on agents

学完这一课，你能做到

看到一条信息，能判断该写入 memory，还是只存一个指针。你能说出四类记忆在开头怎样加载，能分清新 session 和已有 session 开头装进上下文的东西有何不同，也知道 session 太长时 compact 或新开都会丢细节，所以途中要把该留的写下来。

它也要有自己的耐用存储

always-on agent 会跨过许多次互不相连的 run 工作，要靠 memory 来保持连续。和 event inbox、timers 一样，memory 应当有自己的存储。 原文 · Memory

原文举了产品里的例子：Claude Code 的 auto memory，以及 Messages API 的 memory tool，都表现为一目录文件。对 always-on agent 来说，这些目录应当映射到耐用存储，通常是数据库或对象存储。这样，记忆才能比 worker 活得更久。 原文 · Memory

只存查不回来的东西

一条经验规则是：memory 只应保存 Agent 再也查不回来的东西。如果某件事已经住在别的系统里，例如问题跟踪，你应当存一个指针，而不是再拷一份。 原文 · Memory

四类记忆

原文把 always-on agent 应当保存的记忆分成四类。 原文 · Memory

类型保存什么开头怎样加载
user instructions用户关于 Agent 该怎样行事的说明。因为用户不总在场，这些说明必须能带到下一次。单独放在一个文件里，每次 run 开头都加载。 原文 · Memory
user notesAgent 学到的关于用户的事，例如角色、偏好，或用户给过的纠正。可以从一个文件开始，变多后拆成许多小文件；后一种情况下，开头只加载索引，需要细节时再把个别文件拉进上下文。 原文 · Memory
past messages已经对用户说过的话，用来避免把同一件事再说一遍。可以单独成一个每次开头都加载的文件，也可以由 worker 载入最近几条。 原文 · Memory
task progress每个进行中的任务一份进度，写清已经做完什么、还剩什么，好让新的 run 接着上次。和 user notes 一样，开头通常只加载索引，需要时再拉个别文件。 原文 · Memory

以上说的，都是在一次 run 里面写下的记忆。 原文 · Memory

dreaming：点到即可

原文还提到，你可以再加上 dreaming：在 run 之外回顾过去的 session，用来整理 memory。它可以替换过时的条目，并找出只在许多次 run 里才看得出来的模式。 原文 · Memory 原文把细节指向另一篇 The components of agent memory。那是补充阅读，本课不展开。

上下文里的 overhead

在开始做任何工作之前，Agent 会先加载 system prompt、工具定义，以及 memory 文件。这一层初始的 context overhead 会出现在每一次 run 里，所以应当保持精瘦，并用 prompt caching 来降低成本。 原文 · Inside the context window

新 session 开头只有这一层 context overhead，加上触发这次 run 的事件。已有 session 则还会带回先前各次 run 里的消息和工具调用。 原文 · Inside the context window

如果一份 session 变得太长，你可以 compact 较旧的消息，也可以新开一份 session。两种做法都会丢掉细节，所以需要留下来的东西，应当在途中就写入 memory。 原文 · Inside the context window

合上原文，60 秒这样讲

「memory 要有自己的耐用存储，并且比 worker 活得更久。规则是只存查不回来的东西；已在别的系统里的，存指针。四类是：user instructions，每次开头都加载；user notes 和 task progress，变多后开头通常只加载索引；past messages，避免把说过的话再讲一遍。每次 run 开头还有 context overhead，要保持精瘦并用 prompt caching。新 session 只有这一层加上触发事件，已有 session 还会带回先前的消息和工具调用。session 太长就 compact 或新开，两种都会丢细节，所以途中要把该留的写入 memory。dreaming 是在 run 之外整理记忆，本课只记这个名字。」
