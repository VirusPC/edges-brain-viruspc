**背景：**
对话里要开一张学习卡，专读 *Harness Engineering: Anatomy, Architecture, and Evolution of Coding Agents*（十一套生产 coding harness 的源码解剖）。挂在看板主题 `learning` 下。
- 论文：[abs](https://arxiv.org/abs/2609.00006) · [PDF](https://arxiv.org/pdf/2609.00006) · [HTML](https://arxiv.org/html/2609.00006)
- 相关延伸（可选）：[Martin Fowler：Harness engineering for coding agent users](https://martinfowler.com/articles/harness-engineering.html)
- 非目标：本卡不实现新 harness、不改 Edges 框架代码

**目标：**
读完后能用自己的话讲清「agent = model + harness」、七子系统各自做什么，并对照至少 2～3 条观察/模式与自己的实践（Edges、Claude Code / Codex 等）。

**动作：**
- 精读论文（优先 HTML/PDF）：定义、七子系统、11+1 系统解剖、13 观察、29 模式、设计建议
- 可选读 Fowler 一文作「用户侧 outer harness」对照
- 把要点与对照结论写入笔记或本卡进展

**完成标准：**
- [ ] 论文主体已读完，卡内或笔记有简短摘要（七子系统 + 自认最重要的 3 条观察）
- [ ] 写出相对 Edges / 自用 coding agent 的 2～3 个可对照点（可被后续实现或教学卡接走）
