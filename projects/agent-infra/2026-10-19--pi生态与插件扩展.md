# pi 生态与插件扩展

> 日期: 2026-10-19（Asia/Shanghai）。star 数为当天实测；npm 下载量为 2026-09 到 2026-10 的最近一个月数据。⚠️ 表示未逐项核实或属于推断。

## 结论

- 基于 pi 做产品，**走插件 / SDK 扩展、锁定版本**是可行路线；**分叉 core** 是陷阱（参照 omp：分叉后整套重写，扩展 API 已不兼容）。
- pi v0.99.0（2026-09-29）起内置 MCP，插件生态里排第一的 `pi-mcp-adapter` 的部分作用会被内置能力替代。
- 除 OpenClaw 外，没有找到成熟的、以 pi 为底座的产品（检索不穷尽 ⚠️）。
