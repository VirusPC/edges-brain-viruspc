# 豆包语音输入与 DJI Mic 3

> 手机与电脑端语音输入的默认选型，以及和无线麦的搭配结论。

## 背景

本轮从大疆 DJI Mic 3 开机与电脑识别开始，延伸到各端语音输入法怎么选。目的是确认电脑能否稳定用无线麦做语音输入，并定下手机与电脑统一的输入法偏好。

## 主题

在个人日常场景里，比较豆包输入法、Wispr Flow、智谱 AutoGLM 输入法的语音体验，并把 DJI Mic 3 接进 Mac 作为输入源。

- 难点一：官方文案写「实时转换」，和自己用时「松开才出字」不一致，容易误判哪款真能边说边上屏。
- 难点二：无线麦是否经扩展坞被系统识别为可用输入设备。

## 过程

### 下午 大疆 Mic 3 开机与接收器

从充电盒取出发射器会自动开机；否则长按电源键。接收器同样长按开机。接收器指示有信号后，经绿联 CM511（DisplayLink Hybrid Dock）接到 MacBook Pro，系统音频输入出现「Wireless Mic Rx」（厂商 DJI Technology Co., Ltd.，2 声道）。Rx 表示接收端（Receive），Tx 表示发射端（Transmit）。当即要求助手把该设备记入资产相关记忆。

### 下午 语音输入法横向比较

先问手机端最好用的语音输入法，本人倾向豆包输入法。再问电脑端：提到智谱 AutoGLM（智谱 AI 输入法）、市场占有率（搜狗、百度、讯飞等传统输入法份额仍高）、各模型厂对应产品（豆包有输入法；智谱有桌面输入法；腾讯有搜狗/微信；百度文心、讯飞星火；MiniMax 主要是 ASR API 与海螺语音 TTS，没有独立输入法；阶跃星辰有阶跃 AI App 与 StepAudio 等能力，没有输入法产品）。

### 下午 Wispr Flow 与 AutoGLM 是否「实时」

本人反馈 Wispr Flow 手机端不能实时转文字。查官方说明：Wispr Flow 本体是录完再插入文本，只有 Notetaker 有直播式转写。又问 AutoGLM 是否实时；助手曾按文档「实时转换为文字」理解为按住 Fn 时边说边上屏。本人实测纠正：**没有实时转文字**，表现与 Wispr Flow 类似，松开后才一次性上屏。助手据此改口。

### 下午 豆包是否有电脑端

问豆包有没有 PC 端。官网已提供 macOS 下载；页面上 Windows 入口当时呈灰色。新闻侧曾报道 Windows 版上线并宣称覆盖五大平台，以官网当前可点入口为准。macOS 语音快捷键为 Fn；Windows 侧文档为长按右 Alt。

### 傍晚 选型结论

本人明确：不论手机还是电脑，语音输入仍是豆包最好用；Wispr Flow 与 AutoGLM 都不支持实时展示转写结果；配合 Mic 3 使用体验好。助手将该偏好写入跨助手共享记忆。

## 结果

- 已确认 DJI Mic 3 接收器可经绿联 CM511 被 macOS 识别为 USB 音频输入「Wireless Mic Rx」。
- 已定默认语音输入法：**豆包输入法**（手机与电脑），核心理由是边说边实时上屏。
- 已排除 Wispr Flow、智谱 AutoGLM 作为「需要实时上屏」场景的首选。
- 助手记忆已更新；本笔记待审阅后落在个人大脑仓 `notes/`。
- 未做：正式资产台账条目是否单独再写一篇设备档案笔记；Windows 版豆包在官网是否可下，未在本机验证。

## 所学

- 「实时」在产品文案里经常只表示识别快、松键后很快出字，不等于说话过程中持续上屏。以自己屏幕上是否边说边出字为准，不要只信文档措辞。
- 相关可选项：Wispr Flow（英文场景与整理能力强，但不实时上屏）、智谱 AutoGLM（桌面按键简单，同样不实时上屏）、讯飞等传统输入法（份额高，未在本轮深度实测）。最终认豆包，是因为实时上屏对纠错与节奏最重要。
- 无线麦走扩展坞时，先看系统声音输入列表是否出现接收器设备名，再谈输入法；设备没进系统时换输入法也没用。

## 行动指南

### 主题行动指南

#### 背景

日常需要长时间语音输入，且希望说错立刻看见、立刻改，而不是等整段结束。

#### 核心问题

选哪款输入法，以及用什么麦克风，才能在手机和电脑上得到「边说边出字」的体验。

#### 核心解决方案

1. 默认安装并启用豆包输入法（手机与电脑都装），语音输入用它的按键说话流程。相关可选项是 Wispr Flow / AutoGLM；不做它们当默认，因为不能实时展示转写。
2. 需要更好收音时，用无线麦接收器接到电脑（可经带 USB 的扩展坞），在系统声音输入里选接收器对应设备，再开豆包语音。
3. 评判候选输入法时，亲自试一轮：说话过程中屏幕是否持续出字；文档写「实时」只能当线索，不能当结论。

#### 验收标准

- 说话过程中，输入框或预览区持续出现文字，而不是松键后一次性跳出。
- 电脑系统声音输入能选到无线麦接收器，且豆包语音用的是该输入源。
- 手机与电脑都固定用同一款默认语音输入法，减少切换成本。

### 细节与其他

#### 若在 Mac 上用 DJI Mic 3

则：接收器经绿联 CM511 一类 USB 扩展坞接入即可；系统里设备名一般为「Wireless Mic Rx」。当时未比较其它坞，因为现有坞已经识别成功。

#### 若官网 Windows 入口是灰的

则：先用已亮起的 macOS 下载；Windows 是否可装以官网当前状态或应用商店为准，不要只凭新闻稿。

#### 若有人推荐「实时 ASR」桌面工具

则：先问清是「松键后快速出字」还是「边说边上屏」；本环境默认要后者。
