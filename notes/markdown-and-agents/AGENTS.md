
1. 整体风格
	1.  要求有故事性、有逻辑性、框架清晰。
	2. 以 AI Coding 场景和日常提效为主
	3. 多搜索。要求有明确参考，且有参考的地方附上链接。
2. 大纲
	1. 顶层结构直接按发展平铺开，顺序固定为：引言 => 发展史*n  => 总结与展望。
	2. 每一阶段都先讲清楚当时遇到的核心问题，再讲解决思路、典型做法、代表案例，并自然引出下一阶段。
	3. 阶段之间保持大致时间顺序；具体案例允许存在时间交叉，但叙事主线不能乱。
	4. `AGENTS.md`、子 agents、skills、记忆系统不要再单独并列成一章，而是分别放进对应历史阶段里重点展开。
	5. 展开方法保持一致：问题背景 => 核心思想 => 具体案例（重点考虑 Claude Code 和 OpenClaw）=> 行动指南 => 下一章引子。
	6. 最后展望时，要额外写清仍然存在的问题，例如多 agent 兼容、知识腐化、配置组合选择、如何把个人知识沉淀成团队知识。
	7. 最后总结时，要给出mermaid图
