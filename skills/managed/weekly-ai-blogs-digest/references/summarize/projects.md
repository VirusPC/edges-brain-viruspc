# 开源项目

从 `usable/projects/` 的候选里单独筛选本期要展示的仓库，再写用途和本期变化。文章里提到某个仓库，可以在卡片里关联，不能代替这条项目链路。

产出 `page/projects/{id}.json`。ID 是仓库地址。写不上的事实沿用清洗阶段的缺口，不新编星标或许可。

「GitHub Trending（weekly / all 前 5）」若作为一组出现，标题下面不要写概括前五名字的介绍句。名次仍用清洗结果里的 XML 顺序，不按文件名或数组顺序重排。只收 GitHub 仓库。

项目候选变了，重写受影响的项目卡片和映射到这些 ID 的关键词。文章选文的变化不自动改写项目卡。
