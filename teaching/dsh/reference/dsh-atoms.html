第 1 课 首页

产品分层

Harness
把大模型、工具、会话、权限与多种界面装配成可运行产品的运行时层。DeepSeek Harness 的命令名是 dsh。
大模型（LLM）
负责推理与生成的模型本身；不等于 harness，也不等于网页客户端。
客户端 / GUI
图形或终端外壳。Web UI 只是 dsh 的一种界面组合，不是全部能力。
Cordis
插件框架：服务、类型化事件、可逆副作用。dsh 的「一切皆插件」建在其上。

装配

profile（配置档）
Harness home 中的具名组装：有序组合包列表 + cordis.patch.yml + 可装树外插件。命令 dsh web 选中的是 profile，不是模型名。
bundle（组合包）
Cordis 配置与挂载代码的分发单位。例：dsh-base、dsh-web-app、dsh-sdk-minimal。
patch 层序
空根 → bundles → profile 的 cordis.patch.yml → $DSH_HOME/cordis.patch.yml → --patch。
Harness home
显式配置 → $DSH_HOME → 默认 ~/.dsh。

五类随附 profile

web
浏览器 GUI：聊天、设置、会话。人机日常编码。默认端口 3080，URL 带启动令牌。
headless
一次性任务，打印答案后退出；可 --json / --session-id 供监督进程续跑。默认不开监听端口。不适合当 GUI 多轮点选。
sdk
完整 JSON-RPC（JSON 远程过程调用）服务，建立在 dsh-base 上，给程序嵌 dsh。
sdk-minimal
独立瘦身 SDK 树：排除 base/Web/settings/托管凭据/遥测/文本文件工具/workspace 指令/skill/jobs/subagent；默认 shell + read_image + working_directory。需隔离 workspace。
acp
Agent Client Protocol 自动化通道（stdio），直到断开。
desktop / TUI
desktop 名保留给 Electron。CLI 中的 tui 示例写明「若已安装」——非随附模板。

路径与凭据

profiles/<name>/cordis.patch.yml
设置页写入的现行补丁（web 即 profiles/web/...）。
.credentials.yaml
API 密钥只写存储；界面只保留引用。
legacy settings.yaml
若存在则导入一次并改名为 settings.yaml.imported。
dsh-llm-pi-ai
依赖 @earendil-works/pi-ai 的多提供方适配器；与自有 vendored Pi 相关但包边界不同。

排障口诀

EADDRINUSE …:3080
webserver 绑定失败；其它插件等待服务常为连锁结果。Mac：lsof -nP -iTCP:3080 -sTCP:LISTEN 后 ps 核对；或 dsh web --port 3081 / --port 0。勿无差别 pkill。
空目录 ≠ 沙箱
只降低误改真项目的概率；SAFETY：沙箱不保证隔离。
