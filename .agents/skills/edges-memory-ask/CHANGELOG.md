## [Unreleased]

## [0.2.0] - 2026-11-02

### Changed

- **主题检索：** 沿材料清单与递归 Project 的实际组成链接选择类型和正文，不再假定固定两跳或要求每个 Project 有 AGENTS。
- **查询范围：** 使用原 scope 与全局 `--project`，区分 `--super` 的虚拟入口和 `--all` 的独立系统发现；同名条目保留真实归属路径。

## [0.1.1] - 2026-10-27

### Changed

- **协议路径：** `PROTOCOL.md` 改到总入口 `edges` 的 `references/memory/references/PROTOCOL.md`。

## [0.1.0] - 2026-10-27

### Changed

- **更名：** 自 `project-memory-ask@2.1.0` 更名为 `edges-memory-ask`。目录名与 `name` 一致。
- **版本线重启：** 从 `0.1.0` 重新计数，不沿用 `2.1.0`。旧 tag `skill/project-memory-ask@*` 仍留在历史提交上。
