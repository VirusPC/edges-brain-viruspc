用户在 2026-10-27 明确当前方向是对外推广 Edges、让别人使用，并提出推广前先完成两项准备：把核心价值点跑完实验，带着数据说话；重新梳理 Skills，方便别人接入。随后又提出补充使用案例，瞄准具体使用场景写文章；这项属于用户提出的推广准备方向，选题与安排尚未确定。

**Why:** 助手此前把重点放在宣讲活动和首批用户推广，用户先澄清为推广，再提出先补实际证据与接入体验，并考虑用场景文章帮助他人理解用途。这是用户表达的方向，不能把扩大传播当作当前首要工作。

**How to apply:**
- 先将对外核心价值主张对应到实验或能力验收，明确对照、指标、实际结果与适用边界；不能把链路冒烟或全文注入的结果直接表述为真实 Agent 按需使用 Edges 的收益。
- 梳理对外 Skills 的组织、发现与接入流程，以外部使用者能接入并完成真实任务为目标；衔接框架仓已有的按模块收敛 Skill 待办。
- 内容准备考虑围绕明确使用场景写案例文章，将场景、实际过程、结果和接入步骤衔接；用户尚未确定首篇选题、文章数量或发布渠道。未经实测的演示方案不能写成已有用户成功案例。
- 具体实验范围、模型、预算、阈值、Skill 映射及实施安排尚未由用户确认，不将助手建议记成已定方案。
- 后续传播围绕目标用户发现、理解、开始使用与持续使用展开；此前助手提出的首批人数、渠道与活动安排仍是建议。

**任务入口：** 用户要求按一个主任务和一系列子任务推进。关联[推广准备主任务](<../../../tasks/site-and-content/backlog/2026-10-27--Edges-对外推广准备实验Skills-与场景案例/INDEX.md>)，分别跟踪实验方案、实验与报告、Skills 梳理、接入验收、案例素材和文章。框架工作沿用框架仓任务，场景内容留在个人公开脑。
