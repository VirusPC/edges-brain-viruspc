# 一键订阅用复制按钮和说明页，提示词只带说明页 URL

这一轮只定一键订阅的界面。查询入口、检查节奏和推送内容仍按 [0005](0005-subscribe-reads-published-latest-json.md)。新期何时算已上线仍按 [0006](0006-ai-news-routine-ends-on-successful-deploy.md)。0005 留到下一轮的说明页地址、复制按钮和入口位置，在这里定下来。

第一版不做个性化界面。按关键词筛选推送仍是已有 backlog：[AI 资讯订阅的个性化关键词筛选](../../../../../projects/2026-09-13--site-and-content/tasks/backlog/2026-11-25--AI-资讯订阅的个性化关键词筛选/INDEX.md)。

出处：这一轮 grill-with-docs，2026-11-25。功能决定已在 main（#609，`900acb6f`）。

列表页 `/ai-news/` 和每一期页都放复制控件。说明页上再放同一只按钮，按钮旁不放「说明」链接。控件不放进站点顶栏，也不放进本周概览正文。列表页的控件在简介段内，排在 RSS 与「每周五上午 9 点开始生成（北京时间）」两行之下、期列表之上；现有 RSS 文字链保留。每期页放在 h1 正下方、备注卡之上。读者是从列表或某一期走进来的，这两处都要能复制；说明页是提示词指向的那一页，页上再放同一只按钮。人已经在说明页上，所以这里不再放「说明」。顶栏是全站导航，本周概览是推送正文。RSS 仍是给人的退路，文字链留着。

一按即复制，没有弹出层。按钮有三态。默认：Lucide `copy`，配色沿用顶栏 Star 胶囊（`.github-star`），点击区至少 44px，文字是「复制订阅提示词」。已复制：Lucide `check`，弱绿，约 2 秒后回到默认。复制失败：文字改为「复制失败」，图标为 Lucide `triangle-alert`，红描边；按钮下方展开已经选中的提示词文字框，供人手动复制；再点一次重试。绿和红是新增的两组状态色，只用于这两态：绿 light `#3f6b3a`、dark `#9cc48d`；红 light `#a3392b`、dark `#e58f7f`。列表页和每期页在按钮旁放「说明」链接，打开说明页。须覆盖手机和桌面、浅色和深色。

说明页地址是站点 base 下的 `/ai-news/subscribe/`。按当前站点配置，写进提示词的完整 URL 是 `https://viruspc.github.io/edges-brain-viruspc/ai-news/subscribe/`。这是提示词里长期有效的地址：以后改节奏或格式，只改说明页。

说明页上有这些内容：给人的口语说明；同一只复制按钮；给 Agent 的完整步骤；一条推送示例；一句「可按关键词筛选，第一版默认推送整期」；底部一行 RSS 退路。给 Agent 的步骤是：入口为已上线的 `latest.json`，部署路径是站点 base 下的 `/ai-news/latest.json`（完整 URL `https://viruspc.github.io/edges-brain-viruspc/ai-news/latest.json`）；检查时刻写死为北京时间（Asia/Shanghai），每天 10:00 一次，周五 21:00 加一次，周六 21:00 加一次；只有新的已上线期才推送；推送本周概览文字和当期页链接；没有新期就保持安静。时刻这样定，是因为发布 routine 周五 09:00 开始生成，部署成功才算结束（[0006](0006-ai-news-routine-ends-on-successful-deploy.md)），当天晚间和次日再各查一次作为兜底。这些步骤的含义以 0005 为准。人先看懂自己在订阅什么；Agent 要执行的步骤、一条对照示例，以及筛选那一句，都放在这一页。RSS 留在页底，给人一条不经 Agent 的退路。

用户复制的短句是：

> 请打开这个说明页，按里面的规则建立一条定时任务，查询最新的 AI 资讯：https://viruspc.github.io/edges-brain-viruspc/ai-news/subscribe/

节奏和格式只写在说明页，不写进这句短句。短句要能贴给通用 Agent，并且在规则改动后仍然有效。

## 设计稿拍板

2026-11-25，视觉&交互&设计专家出具设计稿，用户通过下面三条。上文已按这三条改写。0005 仍不规定部署路径，也不改它已经定下的查询入口和推送内容。

1. `latest.json` 的部署路径是站点 base 下的 `/ai-news/latest.json`。完整 URL 是 `https://viruspc.github.io/edges-brain-viruspc/ai-news/latest.json`。
2. 说明页写死检查时刻，时区为北京时间（Asia/Shanghai）：每天 10:00 一次；周五 21:00 加一次；周六 21:00 加一次。发布 routine 周五 09:00 开始生成，部署成功才算结束（0006）。当天晚间和次日各加一次，用来兜底。
3. 复制按钮三态。默认用 Lucide `copy`，配色沿用顶栏 Star 胶囊，点击区至少 44px。已复制用 Lucide `check`，弱绿，约 2 秒后复原。复制失败显示「复制失败」和 Lucide `triangle-alert`，红描边；下方展开已选中的提示词文字框供手动复制，不弹窗，再点重试。新增两组状态色只用于这两态：绿 light `#3f6b3a`、dark `#9cc48d`；红 light `#a3392b`、dark `#e58f7f`。列表页控件位于简介段内 RSS 与「每周五上午 9 点开始生成」两行之下、期列表之上。每期页位于 h1 正下方、备注卡之上。说明页上按钮旁不再放「说明」链接。

## Considered Options

- 只在列表页，或只在每期页放复制控件。否决：两处都放，说明页再放同一只按钮。
- 放进站点顶栏，或放进本周概览正文。否决：顶栏是全站导航；本周概览是推送正文。
- 用复制按钮替换列表页上的 RSS 文字链。否决：现有 RSS 文字链保留。
- 点击后先打开弹出层，再在层里复制。失败时也用弹窗。否决：一按即复制。失败时在按钮下方展开已选中的提示词，再点重试。
- 说明页上也放「说明」链接。否决：人已经在说明页上。列表页和每期页仍用这条链接打开说明页。
- 检查时刻只写「每天一次，周五晚和周六」。否决：说明页写死每天 10:00、周五 21:00、周六 21:00（Asia/Shanghai）。
- 把查询节奏和推送格式写进复制出去的短句。否决：那些只写在说明页。短句只带说明页的完整 URL。
- 第一版就做按关键词筛选的界面。否决：个性化仍在已有 backlog，本决定不实现。说明页只留那一句。

- 按钮三态：默认是 Lucide `copy` 与顶栏 Star 胶囊配色，点击区至少 44px，文字「复制订阅提示词」；已复制是 Lucide `check` 与弱绿，约 2 秒复原；复制失败是「复制失败」、Lucide `triangle-alert` 与红描边，下方展开已选中的提示词文字框，不弹窗，再点重试。状态色只此两组：绿 light `#3f6b3a`、dark `#9cc48d`；红 light `#a3392b`、dark `#e58f7f`。
