用户说「重跑」「每周跑一遍」时，指的是用现行 skill 原样、从头完整生成：拉订阅源，按章节规则生成，时间窗限定当周。把需求转给云端 Agent 时，指令必须忠实于用户原话。含义有歧义时先和用户确认，不要自行换成「改写旧稿」或「删掉核对不上的条目」。

**Why:**
2026-11-11 用户让重跑 10 期 AI Coding 资讯周报。助手转给云端 Agent 的指令写成「按新模板改写旧稿、核对不上就删」。用户纠正：「我是希望你原封不动的每周跑一遍」。

**How to apply:**
凡「重跑 / 重新生成」类请求，先确认是否按现行 skill 从头跑。转述给云端 Agent 时保留用户原词。事后若要把旧稿内容并回，需用户明确同意（本次用户同意「合并」，才把旧稿里可核对的条目并回去）。
