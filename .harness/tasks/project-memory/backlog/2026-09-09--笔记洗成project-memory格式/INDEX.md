所有笔记需要洗成 project-memory 的格式；过程有种递归感：用记忆规范去整理记忆/笔记本身。

**Why:**
notes / todos / 其它沉淀若格式不一，检索与跨 Agent 继承都会变脆；统一成 project-memory 条目形态（结论 → Why → How to apply，以及 type/slug/索引）是后续规模化的前提。

**How to apply:**
- 盘点现有笔记与相关沉淀，制定「洗成 project-memory 格式」的批量规则与优先级。
- 评估递归边界：哪些仍留在 `knowledge/notes/` / `knowledge/todos/`，哪些升格进 `.memory/`；避免无止境重写。
