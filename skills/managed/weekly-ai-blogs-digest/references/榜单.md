# 榜单

这一节点写期次目录根上的榜单和模型发布，并在快照可消费之后写 `products/boards.json`。不重抓已经落盘的文件来写说明。密钥只用环境变量 `AA_API_KEY`（或 `ARTIFICIAL_ANALYSIS_API_KEY`）和 `OPENROUTER_API_KEY`。没有密钥就跳过该文件，在 manifest 写明，不用空文件假装有数据。

## 抓取

窗口定了就可以和 [采集](采集.md) 并行。AA 全量不按文章窗口过滤。Arena 用窗口结束日。OpenRouter 用量用窗口。官方端点等 AA。

```bash
PY=/tmp/weekly-ai-blogs-digest-py312/bin/python
$PY scripts/fetch_artificial_analysis.py --limit 0 \
  --out /path/to/ai-news-data/issues/YYYY-MM-DD/aa-language-models.json
$PY scripts/fetch_llm_arena.py --until YYYY-MM-DD \
  --out /path/to/ai-news-data/issues/YYYY-MM-DD/llm-arena-YYYY-MM-DD.json
$PY scripts/fetch_openrouter.py --since YYYY-MM-DD --until YYYY-MM-DD \
  --out-dir /path/to/ai-news-data/issues/YYYY-MM-DD
$PY scripts/fetch_openrouter_endpoints.py \
  --aa /path/to/ai-news-data/issues/YYYY-MM-DD/aa-language-models.json \
  --out /path/to/ai-news-data/issues/YYYY-MM-DD/openrouter-official-endpoints.json
```

`aa-language-models.json` 保留 `performance` 四个中位数和 `performance_v3` 三个均值。这两份速度是备份，不参与卡片上的速度排名。端点目录的宇宙、官方标准档和 latency 口径以 `scripts/fetch_openrouter_endpoints.py` 为准。没有 `OPENROUTER_API_KEY` 就写成 `skipped: true`。

模型发布在 AA、用量文件和端点有了结果之后写入 `model-releases.json`。价格先用发布原文，原文没有再用 OpenRouter 官方提供商。速度用官方标准档 latency / throughput。智力指数用 AA，变体记在 `aa.aa_slug`。缺的数字写「暂无」。用量榜的名次不写进模型卡。

```bash
$PY scripts/model_release_ranks.py \
  --aa /path/to/ai-news-data/issues/YYYY-MM-DD/aa-language-models.json \
  --endpoints /path/to/ai-news-data/issues/YYYY-MM-DD/openrouter-official-endpoints.json \
  --releases /path/to/ai-news-data/issues/YYYY-MM-DD/model-releases.json \
  --out /path/to/ai-news-data/issues/YYYY-MM-DD/model-releases.json \
  --pretty
```

价格排名用同一份 AA 的标价，指标 `blended_input_plus_3_output_over_4` = (输入价 + 3 × 输出价) / 4。速度排名用端点 `latency_s`。排名脚本不改已经写好的价格、速度和智力指数名次。对不上或目录 skipped 时，对应 `rank` 为 null。

AA、端点或官方报价变了，重算用到这次变化的模型事实、排名和榜图说明。整张用量榜变了，只重写 OpenRouter 那几张榜的说明，不重写文章。

## 榜图说明

`products/boards.json` 的 `node` 是 `boards`。`inputs` 引用实际读过的 AA、Arena、三份用量和 `model-releases.json`；缺的记 skipped。`rows` 顺序是 Artificial Analysis、LLM Arena、OpenRouter 的本周用量、编程用量、应用用量。某一张没有就 `omitted: true` 并写 `reason`，不留空标题。

没省略的一行有 `id`、`title`、`caption`、`data`。`data` 只引用榜单文件的路径和 sha256，不把整份榜复制进来。`caption` 是给读者的一句：这张榜相对上一期可核验的变化；没有对比就只说本期格局。不写「数据取自」「快照」「抓取于」。圈谁、Arena 的榜单发布日放在 `chart_meta`，读者看不见。没有证据就不写上升、下降或新进。

- Artificial Analysis：按智力指数画 Top 15。红圈只圈窗口内 `release_date` 新发布、且出现在这张 Top 15 上的模型。
- LLM Arena：发布日与上一期页面采用的榜相同时，沿用那张图，caption 写榜没有换。名次变化对照上一期页面实际采用的榜，不用 `prior_publish_date` 代替。
- OpenRouter：编程用量的 caption 写明是 token 用量，不是质量榜。周环比和 CC BY 4.0 出处写进页面 `notes`。

画图用同级 skill [`llm-arena-marked-chart`](../../llm-arena-marked-chart/SKILL.md)。图下的这句话写在 `boards.json`，不在渲染时现编。
