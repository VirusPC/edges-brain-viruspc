## 需要先观察文件，再输入第一句提示词的任务的开发体验

任务设置：开发者明确知道要修改哪个页面，需要将 DataCenter 页面的标题修改为‘xxx’
效果：
- Codex 允许先浏览文件系统，指定具体页面来进行修改
- Cursor Agents Window 也允许
- Claude 不支持先浏览文件系统
- Minimax Code 不支持
- ZCode 不支持
- Kimi Code 不支持
