# 论文十问（Ten Questions for a Paper）

本 skill 基于沈向洋博士提出的"**论文十问**"框架。沈博士指出：判断一篇论文的价值、读懂一篇论文的精髓，乃至训练自己做研究的品味，都可以从回答这十个问题开始。逐一回答这十个问题，就能对一篇论文形成系统、完整、可批判的认识。

## 十问清单

依次回答以下十个问题：

1. **论文试图解决什么问题？**
2. **这是否是一个新的问题？**
3. **这篇文章要验证一个什么科学假设？**
4. **有哪些相关研究？如何归类？谁是这一课题在领域内值得关注的研究员？**
5. **论文中提到的解决方案之关键是什么？**
6. **论文中的实验是如何设计的？**
7. **用于定量评估的数据集是什么？代码有没有开源？**
8. **论文中的实验及结果有没有很好地支持需要验证的科学假设？**
9. **这篇论文到底有什么贡献？**
10. **下一步呢？有什么工作可以继续深入？**

## 使用方法

当用户提供一篇论文（PDF、链接、摘要或片段）并请求分析时：

1. **按顺序作答**：严格按 Q1 → Q10 顺序回答，不跳题、不合并。每题使用"**Qn. 问题原文**"作为小标题。
2. **基于论文内容回答**：答案必须来自论文本身。论文未提及的内容（例如代码是否开源、作者是否知名研究员）如确实无法从论文中判断，应明确说明"论文未提及"或"需要进一步检索"，不要编造。
3. **区分事实与评价**：
    - Q1–Q7 以客观复述为主（论文说了什么）
    - Q8–Q10 需要加入批判性判断（论文做得如何、贡献几何、未来方向）
4. **保持精炼**：每题 2–5 句话即可，抓住要点，避免大段复述摘要。
5. **必要时引用**：关键结论、数字、方法名可在回答中简要标注来源（如章节、图表编号）。

## 注意事项

- 本框架的价值在于**完整性**与**顺序性**——即使某问答案简短，也不应省略。
- 遇到综述、立场论文（position paper）、工程报告等非典型研究论文时，Q3（科学假设）和 Q8（实验支持假设）可能不完全适用，此时应说明论文类型并简要解释该问在本文中的映射或缺失。
- 该框架同样可用于**写作自查**：完成论文初稿后，用十问自问一遍，可快速发现薄弱环节。
