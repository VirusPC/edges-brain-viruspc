Agent 评测术语速查

第 1–2 课配套。掌握后再晋升工作区 GLOSSARY.md。文中 transcript / trace / trajectory 指同一过程记录。

四个原子

task 任务 / 用例
一条有明确输入与成功标准的测试。别名：problem、test case。
trial 试次
对同一 task 的一次完整尝试。因随机性常跑多次。
transcript 轨迹 / 记录
一次 trial 的完整过程记录：输出、工具调用、推理、中间结果。别名：trace、trajectory（同指过程记录，不是另一种对象）。
outcome 结果状态
trial 结束时环境的最终状态（如数据库是否真有订单），不是 agent 说了什么。

grader 三类

grader 评分器
对表现某侧面打分的逻辑；可含多条 assertion / check；可评 transcript 或 outcome；产出 score；不必都用 rubric。
code-based grader
确定性检查（测试、状态、匹配、静态分析等）。能用时优先；脆、难评主观项。
model-based grader
LLM rubric / 断言等。灵活；需与人类校准后才可信。
human grader
人工金标准；用于校准与抽检，成本高。

框架与质量

evaluation harness / 框架
跑评测的基础设施（并发、记录、聚合）。加速不等于质量；质量在 task 与 grader。原文：框架只和你的评测任务一样好。
异常分层排查
用户体感脱节→任务覆盖；换框架分数变→环境/默认判分；全过不动→饱和或 grader 过松。都要读 transcript、核 outcome。
Swiss Cheese
自动评测 + 生产监控 + A/B + 用户反馈 + 人工复核叠防。

诊断失败 trial

先证据后归因
先核 outcome、再读 transcript 与 score，再分 Agent / grader / 任务环境；证据不足不硬判。
起步 20–50
原文建议的早期简单任务规模；非充分样本量证明；来源含真实失败与手工/工单场景。

多 trial 指标

pass@k
同一 task 的 k 次 trial 中至少一次成功。k↑ 通常升。常关心 pass@1。
pass^k
同一 task 的 k 次 trial 全部成功。k↑ 通常降。强调一致性，不是工作流连续 k 步。

乘方示意仅在独立同分布简化下；真实套件以实测为准。

两套套件

capability eval
测「还能做什么」；起步低 pass，用来爬山。
regression eval
测「以前会的还会吗」；应接近 100%，防回退。
graduate
高 pass 的 capability 题迁入 regression，持续守住。
可验证成功 优先检查 outcome；transcript / trace 用来解释 why。能代码验就别只靠模型自评。爬山与守城要分开建套件。
