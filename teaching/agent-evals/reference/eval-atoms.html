Agent 评测术语速查

第 1–2 课配套。掌握后再晋升工作区 GLOSSARY.md。文中 transcript / trace / trajectory 指同一过程记录。

四个原子

task 任务 / 用例
一条有明确输入与成功标准的测试。别名：problem、test case。
trial 试次
对同一 task 的一次完整尝试。因随机性常跑多次。
transcript 轨迹 / 记录
一次 trial 的完整过程记录：输出、工具调用、推理、中间结果。别名：trace、trajectory（同指过程记录，不是另一种对象）。
outcome 结果状态
trial 结束时环境的最终状态（如数据库是否真有订单），不是 agent 说了什么。

grader 三类

grader 评分器
对表现某侧面打分的逻辑；可含多条 assertion / check；可评 transcript 或 outcome。
code-based grader
确定性检查（测试、状态、匹配、静态分析等）。能用时优先；脆、难评主观项。
model-based grader
LLM rubric / 断言等。灵活；需与人类校准后才可信。
human grader
人工金标准；用于校准与抽检，成本高。
可验证成功 优先检查 outcome；transcript / trace 用来解释 why。能代码验就别只靠模型自评。
