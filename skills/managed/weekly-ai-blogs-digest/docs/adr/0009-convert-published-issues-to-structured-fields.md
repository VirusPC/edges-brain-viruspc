# 已发布各期用机械抽取迁到新格式，缺段补写，尽量保留已发布措辞

把六期已发布数据改成 0008 的字段时，有两条路：用 0.0.12 技能全部重生成，或从现有 `text` 抽取字段。决定走机械抽取：能从现有正文拆出来的字段保留原措辞；缺的五段再补写。不为了迁格式而重写已经发布的卡片。

出处：第一轮 grill，2026-11-27。用户把推荐的「六期全部重生成，并重算 overview 和关键词」改成了「从现有 text 机械抽取字段，缺段再补写，尽量保留已发布措辞」。

## Considered Options

- 用新技能把六期全部重生成，模型直接写字段。否决：措辞会整页改掉，和「尽量保留已发布措辞」冲突。更早几期项目卡缺少五段、个别导语字段已经写坏，这些问题用抽取加补写就能处理，不必整期重跑。
- 11-27 机械抽取，更早各期重生成。否决：同一栏目里各期措辞来源不一致；用户要的是尽量保留已发布措辞，不是按期混用两种办法。

## Consequences

- 这次抽取是一次性的数据迁移，不是站点里的兼容层。迁完之后，站点只读字段，校验器不再解析 `text`。
- 10-23、10-30、11-06 的项目卡和 11-13 里不完整的五段需要补写。补写由谁来写、要不要在数据里标明哪些段是后补的，以及迁完后要不要重算 overview 和关键词，都还没有定。
- 以后若用户要求「重跑」，仍按现行技能从头生成，与这次迁移不是同一件事。
