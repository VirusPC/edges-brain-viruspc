# Mission: DSH 架构与 Coding Agent 评估

## Why
能对照源码讲清 DSH 架构，用于评估和比较 Coding Agent。重点是用可追溯的源码证据说明职责、执行流程与扩展边界，而不是仅比较功能名词。

## Success looks like
- 从固定版本源码定位公开接口、默认执行驱动、模型和工具边界。
- 解释一条请求的执行过程，并用文件与符号支持关键判断。
- 用一致的维度比较 DSH 与另一款 Coding Agent；区分已观察事实、推断和待验证项。
- 不看材料复述，并在后续会话完成一次延后复测。

## Constraints
- 本机公开脑 teaching/ 内持久保存；保留可编辑 Markdown 与学习进度。
- 每课只练一个能力；讲解基于固定版本的一手资料。
- 当前经验、可投入时间及能力水平尚未评估。

## Out of scope
- 当前阶段先服务架构评估；不预设你需要从零重写或修改 DSH。
