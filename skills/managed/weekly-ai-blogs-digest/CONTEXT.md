# AI 资讯周报

weekly-ai-blogs-digest 所处理的周报：按覆盖窗口汇总 AI / AI Coding 领域的新进展，让读者在一页里看完。

## Language

**本周概览**：
周报第一章的名称。内容是词云和本周总结。
_Avoid_: 本周关键词（作为章名）

**本周总结**：
对本期已经展示给读者的内容提炼出的若干条主线。
_Avoid_: 数据总结, 正式摘要

**主线**：
本周总结里的一条趋势陈述，点名具体的模型、产品或文章，并带一枚 tag。
_Avoid_: 要点, 章节复述

**主线 tag**：
一条主线上的那一枚代表性词。模型主线的 tag 是能力方向。其他主线的 tag 是这条线的主题。它会加回关键词并提高权重。
_Avoid_: 型号名, 单篇文章标题, 单个项目或产品名, keywords 里的 theme:true

**词云**：
关键词在页面上的展示。只读合并主线 tag 之后的 `keywords.json`。
_Avoid_: 把它和本周总结混为一谈

**关键词**：
先从已精选条目提炼出的词、权重，以及到这些条目的映射，再把主线 tag 并入同一份列表。
_Avoid_: 本周概览, 本周总结, 用 theme:true 表示主线 tag

**overview**：
本周总结这份数据产物的名称。
_Avoid_: 把它和「数据总结」阶段或关键词混为一谈

**引用** / **refs**：
一条主线所依据的条目，以及这些条目在主线正文中的锚文字。
_Avoid_: 占位标记（已否决的写法）

**条目** / **内容 ID**：
已精选内容的稳定身份：文章是规范化链接，项目是仓库地址，模型是官方名。
_Avoid_: 文件名, 标题 slug（作为身份）

**模型主线**：
本周总结的第一条，只写模型能力的发展方向。有模型时要点名型号，但收在这条方向里，不写成发布清单，也不放入文章。它的 tag 是这个方向，不是型号名。没有重要模型发布时，第一条仍是模型主线，文案是「本周无重要模型发布」，tag 是「无重要发布」。
_Avoid_: 发布清单, 型号名当作 tag

**latest.json**：
站点已上线最新一期的机器可读指针。只指向已经部署的期，在站点构建、部署时写入。部署路径是站点 base 下的 `/ai-news/latest.json`（完整 URL `https://viruspc.github.io/edges-brain-viruspc/ai-news/latest.json`）。订阅 Agent 查最新一期时，它是唯一的主查询入口。
_Avoid_: 把仓库 raw JSON 或 RSS 当主入口, 指向尚未部署的期

**一键订阅** / **订阅提示词**：
用户复制给自己的 Agent、用来建立定时查询的短句，并带上说明页的完整 URL。定稿是：「请打开这个说明页，按里面的规则建立一条定时任务，查询最新的 AI 资讯：https://viruspc.github.io/edges-brain-viruspc/ai-news/subscribe/」。节奏和推送格式只写在说明页上。
_Avoid_: 平台专有语法, 把完整指令、查询节奏或推送格式写进这句短句, OPML 信源清单

**复制订阅提示词按钮**：
列表页、每期页和说明页上的同一只复制控件。一按就把订阅提示词复制到剪贴板。按钮文字是「复制订阅提示词」，成功后约 2 秒显示「已复制」。列表页和每期页在按钮旁放「说明」，打开说明页；说明页上不放这条链接。图标用 Lucide。
_Avoid_: 弹出层, 放进站点顶栏, 放进本周概览正文

**说明页**：
承载完整订阅指令的页面。订阅提示词只指向它。地址是站点 base 下的 `/ai-news/subscribe/`。检查时刻写死为北京时间（Asia/Shanghai）：每天 10:00 一次，周五 21:00 加一次，周六 21:00 加一次。
_Avoid_: 用粘贴文本代替这份完整指令, 换成别的路径

**已上线期**：
已经部署到正式站点、且被 `latest.json` 指向的期。
_Avoid_: 仓库里已合并但尚未部署的期
