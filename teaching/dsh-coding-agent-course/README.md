# DSH · 用源码判断架构

本轮已实际加载并按本机安装的 Matt Pocock teach skill 执行。学习目标由学习者确认：对照源码讲清架构，用于评估和比较 Coding Agent。

## 开始第一课

打开 [课程首页](index.html)，进入 [0002 · 控制接口与执行驱动](lessons/0002-agent-and-driver.html)。一次只练一个判断：看到一项行为后，知道应去公开接口还是默认循环寻找证据。

- [MISSION](MISSION.md)：本课程的目标与边界。
- [RESOURCES](RESOURCES.md)：固定版本的一手资料与资料缺口。
- [课程目录](lessons/README.md)：已生成课页与后续候选主题。
- [进度](progress/README.md) 与 [日志](progress/learning-log.md)：保存当前状态和实际学习活动。
- [概念速查](reference/architecture-boundary.html) 与 [GLOSSARY](GLOSSARY.md)：分别放课前参考与已掌握术语。
- learning-records/：按 teach 规则，在首次出现真实学习证据时创建；不把活动日志冒充学习记录。

## 持续编辑与继续学习

课页有对应 Markdown 源文件。答题草稿保存在当前浏览器，可导出 Markdown；浏览器不能自动修改本地仓库。把答案交给 Agent 后，依据实际表现更新 progress/，达到标准再新增 learning-records/ 和术语。

下次说：“继续这份 DSH 课程，先读 MISSION、RESOURCES、progress 和已有 learning-records，再复习上一课。”

本地文件长期保存；Artifacts 是有时限的静态快照，后续编辑需要重新发布。
