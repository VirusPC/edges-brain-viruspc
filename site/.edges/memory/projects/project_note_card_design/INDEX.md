AI News 的项目开源卡和精选文章卡共用 `site/src/components/NoteCard.astro`。改这个组件或它的样式时，按下面六条做。这是用户 2026-11-21 定稿，不是从样式反推的临时偏好。

1. 整页只用一套视觉语言。卡片里的分类和来源用筛选栏同款胶囊，分类用该分类的颜色，来源白底灰框。卡片里的字全用宋体，不另引一套字体。
2. 在原有卡片上做最小改动，不堆纸张装饰。不要横线纸、页边线、胶带、倾斜，也不要改卡片底色、边框和标题原来的位置、颜色、下划线。横线如果和字对不齐，会干扰阅读。
3. 层次靠字号、字重和颜色小步拉开。标题、完整总结、正文、小标题各挪一小步，不做夸张的大小落差。
4. 强调只留荧光笔一种，而且用得省。只划一句话总结里已经标出的关键词，以及「洞察与启发」整句。其他段不做特殊处理。没有关键词标记就不要编一个出来划。
5. 结构让人一眼扫完。桌面端小标题放左栏，灰棕色、不加粗、右对齐、不换行，和正文首行对齐。窄屏大约 520px 及以下，小标题回到正文上方。
6. 能删的装饰就删。小标题下的弧线、相关段单独改成灰色，这类可有可无的处理都不加。留下的每个元素都有用处。

展示名只改第一段：源稿仍写「解决什么问题」，卡片上显示「什么问题」。如何解决、效果怎样、洞察与启发、相关工作保持原名。折叠标题仍叫「完整总结」。

**Why:**
上一版想用横线纸、胶带和倾斜做出笔记感，线和字一对不齐就更难读，也和站点原来的卡片抢风格。用户把范围收成三处：胶囊与标题仍在同一行、荧光笔只划关键词和洞察、小标题改成左栏。手写感应该停在筛选栏已有的胶囊上，不要再加一层纸张道具。

**How to apply:**
- 项目开源和精选文章都走 `NoteCard.astro`。没有分类、来源、一句话或某一段时照样能排，不要为了复用把两种卡片塞成同一种数据。
- 筛选栏的样式文件不要改。卡片上的胶囊复用同一套 class。
- 卡片里不要引入 Caveat、马善政或其他手写字体，也不要加横线、页边线、胶带、倾斜。
- 一句话总结只渲染源稿里的 `<mark>`。现有日报没有这个标记，就整句不划。「洞察与启发」整句用同一支荧光笔。
- 小标题在展示层映射。源稿和周报模板继续写「解决什么问题：」，不要为了显示名去改已有日报。
