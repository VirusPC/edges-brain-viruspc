# AI 资讯周报

weekly-ai-blogs-digest 所处理的周报：按覆盖窗口汇总 AI / AI Coding 领域的新进展，让读者在一页里看完。

## Language

**本周概览**：
周报第一章的名称。内容是词云和本周总结。
_Avoid_: 本周关键词（作为章名）

**本周总结**：
对本期已经展示给读者的内容提炼出的若干条主线。
_Avoid_: 数据总结, 正式摘要

**主线**：
本周总结里的一条趋势陈述，点名具体的模型、产品或文章。
_Avoid_: 要点, 章节复述

**词云**：
关键词在页面上的展示。
_Avoid_: 把它和本周总结混为一谈

**关键词**：
从已精选条目提炼出的词、权重，以及到这些条目的映射。
_Avoid_: 本周概览, 本周总结

**overview**：
本周总结这份数据产物的名称。
_Avoid_: 把它和「数据总结」阶段或关键词混为一谈

**引用** / **refs**：
一条主线所依据的条目，以及这些条目在主线正文中的锚文字。
_Avoid_: 占位标记（已否决的写法）

**条目** / **内容 ID**：
已精选内容的稳定身份：文章是规范化链接，项目是仓库地址，模型是官方名。
_Avoid_: 文件名, 标题 slug（作为身份）

**模型主线**：
本周总结的第一条，只写模型。没有重要模型发布时，第一条仍是模型主线，文案是「本周无重要模型发布」。
