# 选文

快照可消费之后开始。只读 `feeds.index.json`、`github-trending.json` 的标题和 XML 名次，以及存在的 `user-backfill.json`。不打开 `feeds.json`，不为了挑选去看网页，也不读关键词。

产出 `products/selection.json`。`node` 是 `selection`。`inputs` 引用索引、trending，以及补录（没有清单就不引用）。`rules.path` 指向本文件。

`rows` 里每条有 `link`、`title`、`section`、`date`。`section` 是模型进展、项目开源，或精选文章下的国内模型厂、国外模型厂、国内非模型厂、国外非模型厂。补录另加 `backfill: true`，`date` 保持原发日。

完成时，每条都能指回索引、trending 或补录。窗口外的不进表。补录全部留在本期。weekly/all 取 XML 顺序的前 5。项目开源只收 GitHub 仓库。Hugging Face 博客和其他非 GitHub 链接不放进项目开源；仍值得写的归到精选文章。侧重 Agent 与产品。研究向、红队、纯学术长文可以不写。融资、IPO、营收、定价套餐、厂商自写客户案例不收，除非其中有具体技术或产品细节。优惠和白嫖不写。判断依据是标题、来源和开头。

索引或 trending 变了就重做这张表。补录变了也重做。关键词变了不重做。选完才把链接交给 [总结](总结.md)。
