# 认知优势 (Edges)

此目录存放已经提炼出来、可以反复使用的判断，也就是 Edge。Edges 这个名字就来自这里。

## 什么是 Edge

Edge 是已经提炼出理由与适用边界、可检验，并且能相对原有判断或替代方案改善未来决策的可复用判断。它能在某类问题中提高成功概率，或者减少错误成本。单条 Edge 是判断优势；多个相互补充、交叉检验并服务于不同决策的 Edge，共同构成认知资产组合。

## 准入标准

Edge 至少应说明结论、理由、适用边界和检验方式，并满足四项准入标准：未来可以复用，能够影响行动，允许复盘或证伪，并能随新经验继续演化。现实验证可以记录，但不是成为 Edge 的前提。

Edge 也有认知风险：证据可能不足，判断可能被越界使用，价值可能随环境衰减，也可能被新证据反驳。对新增 Edge，可以逐步观察置信度、验证证据、复用记录、最近复查时间、失效条件和衰减风险。这些是帮助判断与演化的观察维度，不是统一的 ROI、Alpha 或综合评分。

## 从哪里来，怎么演化

从 Note 或专项形成 Edge 是提炼，不是移动原文或复制全文。外部反馈首先作为新材料回到 Note 或对应专项，经过判断后再用于演化 Edge：

- 不改变判断含义的勘误、证据和链接补充，可以原地修改。
- 适用边界、因果解释或结论发生实质变化时，创建继任 Edge，并标明替代关系。
- 被替代的旧 Edge 归档到对应的 `archive/edges/` 路径，规则见 [archive/README.md](../archive/README.md)。

## 目录约定

每条内容使用 `主题--核心洞察/INDEX.md`，图片等附件与入口放在同一个目录。分类目录可以继续嵌套，交叉引用指向明确的入口文件；已有内容的标题和分类保留。例如 `监控设计--三层次原则/INDEX.md`，配图放在该目录中。

以上是新增内容和后续维护的约定。历史导入内容已完成目录入口转换，但尚未全部按准入标准整理；目录化不代表其结论已经验证，现有内容也尚未按上述观察维度记录。
