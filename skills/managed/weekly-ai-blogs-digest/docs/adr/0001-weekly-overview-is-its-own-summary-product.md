# 本周总结是独立的 summary 产物

本周总结是对已经展示给读者的内容做提炼，需要单独存、单独校验、单独重算。决定新建名为 overview 的数据产物，由 Agent 按子步骤说明里的提示词撰写，脚本只做校验。某一期缺少这份产物时，站点构建直接失败，不为旧期写兼容分支。

2026-11-24：[0004](0004-theme-tag-before-keywords.md) 覆盖了本篇里的两处决定：「overview 排在关键词之后」和「撰写时要读关键词」。这两条不再执行。overview 仍是独立产物，不并进 index 或 keywords。编排重构和 GitHub Trending 每周总榜都已完成，概览已在 0.0.8 落地；「等另外两件事做完再实现」不再构成等待。

当时的实施顺序是等 skill 编排重构和 GitHub Trending 改动完成。出处：第二轮 grill，2026-11-23。用户把推荐的「本周概览可以单独现在做」改成了「等另外两个事做完先」。这两件事已经完成。

## Considered Options

- 并入 `index.json` 或 `keywords.json`。否决：一个步骤对应一份文件；`index.json` 只排章节和 ID，不另写摘要；关键词文件不能同时承担两份产物。
- 与关键词并行生成。否决当时的理由是：总结要引用本期关键词，并和词云互相印证；上游一变，总结必须重算。已被 0004 覆盖：主线先写，关键词随后把主线 tag 并进来。主线不再读取关键词。卡片变了，主线和关键词都要重算。
- 用 `cleaned/` 全量候选，或再参考覆盖统计。否决：总结不该引入页面上看不到的条目；覆盖统计已出现在信息源卡和精选篇数里。
- 由脚本调用 LLM API 生成。否决：流程以 skill 为主体，脚本只当工具。

## Consequences

- 正文与引用列表分开存：`text` 是纯文本，`refs` 是 `{id, label}`，`label` 必须是正文里的原文。站点渲染时再做成链接。出处：第二轮 grill，2026-11-23。
- 输入只用本期 summary 里已精选的内容和关键词。出处：第一轮 grill，2026-11-23。已被 0004 覆盖：撰写主线时只读三路已精选卡片，不读关键词。
- 采用第二轮 plan 里按 3 到 5 条、每条不超过 100 字、首条为模型改过的提示词草稿；第一条之后的主线按重要性排序，不按章节顺序。出处：第二轮 grill，2026-11-23。
- 最近五期都生成并发布，但只补 overview，并改 `index.json` 的第一章标题和 skill 版本，不把整个 summary 阶段从头重算。实现时 skill 版本只升 patch，不升 minor 或 major。出处：第一轮 grill（五期都发布），2026-11-23；范围收窄为「只补 overview」是第二轮 grill，2026-11-23；版本只升 patch 是用户于 2026-11-23 针对本技能另定的规则。
- 不和尚未完成的 skill 编排重构、GitHub Trending 改动放进同一个变更。出处：第二轮 grill，2026-11-23；执行顺序由用户改为先做完那两件事。

## 决定清单

下列已定事项凡满足「难以回退、没有上下文会让人意外、是真实权衡」三条的，已经写入本 ADR 或 [0002](0002-overview-chapter-cloud-then-summary.md)、[0003](0003-github-trending-weekly-all-only.md)。其余记录在这里，避免散落在对话里。

1. 新建 `summary/overview.json`。当时把它放在 summary 阶段最后一步，排在模型、项目、文章和关键词之后。出处：第一轮 grill，2026-11-23。顺序已被 0004 覆盖：汇合之后先写主线，再抽词。
2. 由 Agent 按子步骤说明里的提示词撰写，脚本只做校验。出处：第一轮 grill，2026-11-23。
3. 输入当时只用 summary 里已精选的内容加关键词。出处：第一轮 grill，2026-11-23。已被 0004 覆盖：撰写时不读关键词。
4. 正文与引用列表分开存：`text` 是纯文本，`refs` 是 `{id, label}`。出处：第二轮 grill，2026-11-23。
5. 采用第二轮 plan 里改过的提示词草稿；第一条之后按重要性排序。出处：第二轮 grill，2026-11-23。
6. validator 按第二轮 plan 里的报错和警告划分执行，但删掉「本期没有模型卡片，但首条不是这句原文」这一条。出处：第二轮 grill，2026-11-23；删除该条是用户改了推荐方案。
7. 最近五期都生成并发布，只补 overview，并改 index 的章名和 skill 版本。出处：见上。
8. 某一期没有 overview 时，站点构建直接失败。出处：第二轮 grill，2026-11-23。
9. 等 skill 编排重构和 GitHub Trending 改动做完之后，再做本周概览。出处：第二轮 grill，2026-11-23。用户原话：「等另外两个事做完先」。这两件事已经完成，概览已在 0.0.8 落地。不要再把这句话当成还要等待。
