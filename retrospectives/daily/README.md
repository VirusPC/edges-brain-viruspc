# 日复盘

命名：`retrospectives/daily/<日历日>--日复盘/INDEX.md`（日期取回看结束时刻所在的日历日；例 `retrospectives/daily/2026-10-12--日复盘/INDEX.md`）。同一日只保留一篇，补记改原来的 `INDEX.md`。

`INDEX.md` 的一级标题是 `# <YYYY-MM-DD> 日复盘`。必写二级标题「范围」和「建议补充内容清单」。其余四节可省略；若写，同样用二级标题，顺序跟 [周复盘](../weekly/README.md) 一致：本该怎样、实际怎样、为什么、下次做什么。

每日沉淀扫描由 [日复盘 routine](../../.harness/routines/daily-conversation-deposit/INDEX.md) 产出。候选直接落成文件，和这篇日复盘放进同一个开到 main 的 PR（个人内容在 edges-brain-viruspc-private 另开 PR）。「建议补充内容清单」列出本次 PR 里落了哪些候选；扫描局限写进「范围」。审阅在 PR 上，不自动合并。

本仓公开。不写个人身份细节、未公开 IP、鉴权链接、凭据、私人生活细节。私人正文只进 edges-brain-viruspc-private 的 PR；公开这篇只记「有 N 条私人内容已在 edges-brain-viruspc-private 开 PR」并附链接。原始对话记录不进本目录。细则见根 [README](../../README.md) 的「隐私与脱敏」。

## 范围

一两行：时间窗，以及看了哪些来源（仓库、各助手对话）。

## 建议补充内容清单

该进 Harness 的 Memory / Skill / Note / Task / `AGENTS.md` 硬约束候选。每条一句话，加上建议去处，以及处理结果：本次 PR 中的写入路径、不做原因，或留待触发条件。本次 PR 里落了哪些候选列在这里。没有就写明没有。
