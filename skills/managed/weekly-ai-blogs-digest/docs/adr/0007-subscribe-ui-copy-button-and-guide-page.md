# 一键订阅用复制按钮和说明页，提示词只带说明页 URL

这一轮只定一键订阅的界面。查询入口、检查节奏和推送内容仍按 [0005](0005-subscribe-reads-published-latest-json.md)。新期何时算已上线仍按 [0006](0006-ai-news-routine-ends-on-successful-deploy.md)。0005 留到下一轮的说明页地址、复制按钮和入口位置，在这里定下来。

第一版不做个性化界面。按关键词筛选推送仍是已有 backlog：[AI 资讯订阅的个性化关键词筛选](../../../../../projects/2026-09-13--site-and-content/tasks/backlog/2026-11-25--AI-资讯订阅的个性化关键词筛选/INDEX.md)。

出处：这一轮 grill-with-docs，2026-11-25。功能决定已在 main（#609，`900acb6f`）。

列表页 `/ai-news/` 和每一期页都放复制控件。说明页上再放同一只按钮。控件不放进站点顶栏，也不放进本周概览正文。列表页的控件放在标题和简介（dek）附近，现有 RSS 文字链保留。每期页放在页头，标题下面。读者是从列表或某一期走进来的，这两处都要能复制；说明页是提示词指向的那一页，页上再放同一只按钮。顶栏是全站导航，本周概览是推送正文。RSS 仍是给人的退路，文字链留着。

一按即复制。按钮文字是「复制订阅提示词」。复制成功后约 2 秒显示「已复制」。没有弹出层。按钮旁有「说明」链接，打开说明页。图标用 Lucide。须覆盖手机和桌面、浅色和深色。复制在这一下完成；成功态停在按钮上约 2 秒。说明从旁边的链接进去。

说明页地址是站点 base 下的 `/ai-news/subscribe/`。按当前站点配置，写进提示词的完整 URL 是 `https://viruspc.github.io/edges-brain-viruspc/ai-news/subscribe/`。这是提示词里长期有效的地址：以后改节奏或格式，只改说明页。

说明页上有这些内容：给人的口语说明；同一只复制按钮；给 Agent 的完整步骤；一条推送示例；一句「可按关键词筛选，第一版默认推送整期」；底部一行 RSS 退路。给 Agent 的步骤是：入口为已上线的 `latest.json`；每天查一次，周五晚和周六各加一次；只有新的已上线期才推送；推送本周概览文字和当期页链接；没有新期就保持安静。这些步骤的含义以 0005 为准。人先看懂自己在订阅什么；Agent 要执行的步骤、一条对照示例，以及筛选那一句，都放在这一页。RSS 留在页底，给人一条不经 Agent 的退路。

用户复制的短句是：

> 请打开这个说明页，按里面的规则建立一条定时任务，查询最新的 AI 资讯：https://viruspc.github.io/edges-brain-viruspc/ai-news/subscribe/

节奏和格式只写在说明页，不写进这句短句。短句要能贴给通用 Agent，并且在规则改动后仍然有效。

## Considered Options

- 只在列表页，或只在每期页放复制控件。否决：两处都放，说明页再放同一只按钮。
- 放进站点顶栏，或放进本周概览正文。否决：顶栏是全站导航；本周概览是推送正文。
- 用复制按钮替换列表页上的 RSS 文字链。否决：现有 RSS 文字链保留。
- 点击后先打开弹出层，再在层里复制。否决：一按即复制；说明走旁边的「说明」链接。
- 把查询节奏和推送格式写进复制出去的短句。否决：那些只写在说明页。短句只带说明页的完整 URL。
- 第一版就做按关键词筛选的界面。否决：个性化仍在已有 backlog，本决定不实现。说明页只留那一句。

## Consequences

- 列表页 `/ai-news/` 的标题和简介（dek）附近、每一期页的页头（标题下），以及说明页 `/ai-news/subscribe/`，使用同一只复制按钮。按钮文字是「复制订阅提示词」，成功后约 2 秒显示「已复制」。旁有「说明」链接，打开说明页。图标用 Lucide。没有弹出层。不放进站点顶栏，不放进本周概览正文。列表页保留现有 RSS 文字链。
- 说明页在站点 base 下的 `/ai-news/subscribe/`。提示词中的完整 URL 是 `https://viruspc.github.io/edges-brain-viruspc/ai-news/subscribe/`。
- 说明页包含口语说明、同一只复制按钮、给 Agent 的完整步骤、一条推送示例、筛选那一句，以及底部一行 RSS。Agent 步骤仍是 0005：读已上线的 `latest.json`；每天一次，周五晚和周六各加一次；仅新的已上线期才推送本周概览文字和当期页链接；无新期保持安静。
- 第一版没有个性化界面。按关键词筛选不在本决定里实现。
- 本篇只记录决定，不改站点代码、脚本、routine 或 CI，也不升技能版本。按钮和说明页的落地留到后续实现。实现时须覆盖手机和桌面、浅色和深色。
