# 02 选文

只读 `issues/YYYY-MM-DD/feeds.index.json` 和 `github-trending.json` 的标题与名次。不要打开 `feeds.json`，也不要为了挑选去看网页。

侧重 Agent 与产品：编码工具、harness、企业落地。研究向、红队、纯学术长文可以不写。融资、IPO、营收、定价套餐、厂商自写客户案例不收，除非其中有具体技术或产品细节。优惠和白嫖不写。

判断依据是索引里的标题、来源和开头，不是 URL 路径。链接必须是快照里出现的地址。

GitHub Trending 只保留 weekly / all 的前 5，订阅 id 是 `github-trending-weekly-all`。名次按 Trending feed 的 XML 原始顺序，不要用 `feeds.json` 或 `github-trending.json` 里按标题排过的顺序，也不要编造名次。摘录文件仍叫 `github-trending.json`，里面只放这一条 weekly / all。Python、TypeScript 的 weekly 源只留在 `feeds.json`，不写进正文。这 5 条的 README 全文留到下一步用 `--pick` 读，选文时只看标题。

「项目开源」只收 GitHub 仓库：这一周榜的前 5，以及其他确实是 GitHub 仓库的开源项目。Hugging Face 博客和其他非 GitHub 链接不放进这一节。仍值得写的，归到「精选文章」。

窗口外的条目不选。`fetch_feeds.py` 已按 UTC 日历日切过；索引里的 `date` 就是这个日历日。
