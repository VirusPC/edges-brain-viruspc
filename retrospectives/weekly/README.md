# 周复盘

命名：`retrospectives/weekly/<周一日期>--周复盘/INDEX.md`（周一到周日，日期取该周周一；例 `retrospectives/weekly/2026-10-05--周复盘/INDEX.md`）。同一周一只保留一篇。

`INDEX.md` 的一级标题是 `# <YYYY-MM-DD> 周复盘`。下面六节都是二级标题，顺序固定。

周复盘由 [周复盘 routine](../../.harness/routines/weekly-retrospective/INDEX.md) 产出，经 PR 写入本目录。入口是 Compose 工作区根 `VirusPC/edges-workspace-viruspc`，正文落在本仓。例程运行时只看 GitHub；对话层由主聊天逐个助手补进后再合成。正文 `INDEX.md` 写定后不改，后续评论记同目录 `COMMENTS.md`。

本仓公开。不写个人身份细节、未公开 IP、鉴权链接、凭据、私人生活细节。原始对话记录不进本目录。细则见根 [README](../../README.md) 的「隐私与脱敏」。

## 范围

一两行：时间窗，以及看了哪些来源（仓库、各助手对话）。

## 本该怎样

本周事先的目标，加上上期周复盘「下次做什么」里的行动。没有就写明没有，不事后画靶。

## 实际怎样

可核对的事实，带链接。上期行动逐条标：做成、没做成，或卡住（写原因）。

## 为什么

差距的原因，用「可能因为…」口吻。至少一条做得好、该保持的。

## 下次做什么

至多 3 条。每条写清怎么算完成。

## 建议补充内容清单

该进 Harness 但没进的 Memory / Skill / Note / Task / `AGENTS.md` 硬约束候选。每条一句话，加上建议去处，以及处理结果：已写入路径、不做原因，或留待触发条件。没有就写明没有。
