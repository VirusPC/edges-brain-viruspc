# AI 课程写作风格与方法论

> 核心定位：培养能做理性 AI 工程决策的开发者，而非研究者。

---

## 核心原则

### 1. 工程导向
- 每个技术概念必须有"工程视角"：成本、延迟、选型影响
- 关注"为什么这会影响我的决策"，而非数学推导

### 2. 成本意识
- Token 计费、显存占用、API 价格差异贯穿全文
- 技术选择与经济可持续性绑定

### 3. 具象化表达
- 用类比解释原理
- 优先给代码、配置、命令，而非抽象描述

### 4. 明确反模式
- 直接告诉"不要做什么"
- 警告常见误区和过度工程

### 5. 前沿实践对齐
- 从主流开源项目（Claude Code 和 OpenClaw）提取真实工程模式
- 示例和配置应与当前工业界最佳实践兼容
- 反模式应来自真实生产问题，而非臆想

## 写作规范
- 避免模糊词："通常" → 具体数值
- 用主动语态："模型被训练" → "训练模型"
- 数据支撑："效果更好" → "pass@1 提升 15%"
